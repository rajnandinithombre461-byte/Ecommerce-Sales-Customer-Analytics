# E-Commerce Sales & Customer Analytics

## Project overview
This beginner-friendly portfolio project explores e-commerce order data to understand sales performance, product categories, customer segments, regions, payment methods, discounts, and shipping times.

**Important:** The included dataset is synthetic/sample data generated for learning and portfolio practice. It does not represent a real company or real customer records.

## Business questions
- What are total orders, unique customers, units sold, net sales, profit, and average order value?
- Which product categories and products generate the most sales?
- How do sales and profit change month by month?
- Which customer segments and regions contribute most to sales?
- How do payment methods, discounts, and shipping times vary?

## Tools and skills
- **Excel:** data review, filters, summary tables, KPI summary
- **SQL (MySQL 8+):** aggregation, grouping, sorting, conditional logic, customer analysis
- **Python:** pandas-based checks and summaries; matplotlib charts
- **Power BI:** recommended for an interactive dashboard (see build steps below)

## Files
- `data/ecommerce_orders.csv` — synthetic dataset (1,200 order records)
- `Ecommerce_Sales_Analysis.xlsx` — workbook with order data and summary sheets
- `sql/ecommerce_analysis_queries.sql` — sample MySQL analysis queries
- `analyze_ecommerce.py` — Python analysis script
- `outputs/` — sample charts and category summary generated by the script

## Key metrics
The dataset includes order date, customer, customer segment, region, product, quantity, unit price, unit cost, discount, payment method, shipping days, gross sales, discount amount, net sales, cost, and profit.

Formulas:
- Gross Sales = Quantity × Unit Price
- Discount Amount = Gross Sales × Discount Percentage
- Net Sales = Gross Sales − Discount Amount
- Cost = Quantity × Unit Cost
- Profit = Net Sales − Cost
- Average Order Value = Total Net Sales ÷ Distinct Order Count

## How to use
1. Open `Ecommerce_Sales_Analysis.xlsx` in Excel and inspect the `Orders_Data` and summary sheets.
2. Import `data/ecommerce_orders.csv` into MySQL as `ecommerce_orders`, then run queries from `sql/ecommerce_analysis_queries.sql`.
3. Install dependencies for Python: `pip install pandas matplotlib`.
4. Run `python analyze_ecommerce.py` from this project folder. Charts and summary files will be created in `outputs/`.
5. To create a Power BI dashboard, select **Get Data → Text/CSV**, import `data/ecommerce_orders.csv`, verify `OrderDate` is a Date type and sales/profit columns are numeric, then create cards for Total Orders, Net Sales, Total Profit, Unique Customers, and Average Order Value. Add charts for monthly sales, sales by category, sales by region, and a table of top products. Add slicers for date, region, category, and customer segment.

## Suggested Power BI measures
```DAX
Total Orders = DISTINCTCOUNT(ecommerce_orders[OrderID])

Unique Customers = DISTINCTCOUNT(ecommerce_orders[CustomerID])

Units Sold = SUM(ecommerce_orders[Quantity])

Net Sales = SUM(ecommerce_orders[NetSales])

Total Profit = SUM(ecommerce_orders[Profit])

Average Order Value = DIVIDE([Net Sales], [Total Orders], 0)
```
